This document lists all discrepancies between the README.md documentation and the actual implementation.

DEFECT #1: Command-line arguments not supported
================================================================================
Location: README.md "Quick Start" section
Documentation states:
  ```bash
  python app.py --host=0.0.0.0 --port=8080
  ```

Actual behavior:
  - app.py does not parse command-line arguments
  - app.run(debug=True) uses default host=127.0.0.1 and port=5000
  - Command-line flags are ignored

Reproduction:
  1. Run: python app.py --host=0.0.0.0 --port=8080
  2. Observe: Server starts on http://127.0.0.1:5000 (not 0.0.0.0:8080)

Error trace:
  No error - arguments are silently ignored by Flask app.run()

Fix required:
  Parse command-line arguments using argparse or click, or document correct usage
